# Глоссарий

Термины документации и интерфейса WPS: английские соответствия и имена, которые используются в коде.

<!-- lang-switch -->
[🇬🇧 English](../../en/01-overview/glossary.md) | 🇷🇺 Русский
<!-- /lang-switch -->

Документация на обоих языках использует эти термины единообразно. Технические имена в последней колонке (поля, таблицы,
значения API) не переводятся.

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| процесс | process | `processes` | Настроенное правило автоматизации: тип объекта, условия, предзагрузка и действия. Хранится как JSON `definition`. |
| процесс верхнего уровня | top-level process | `is_child: false` | Процесс, который запускается напрямую событиями CRM своего типа объекта. |
| ведомый процесс | child process | `is_child: true` | Процесс, который запускается только действием `start_process` другого процесса. К событиям стрима напрямую не подбирается. |
| тип объекта (модуль CRM) | object type (CRM module) | `object_type` | Модуль CRM, на который реагирует процесс, например `Deals`, `Accounts`, `Leads`. |
| событие | event | сообщение стрима | Сообщение в Redis Stream `crm_events` о том, что объект CRM сохранён. Содержит поля объекта. |
| объект события / исходный объект | event object / source object | `object` | Объект из события. В процессе доступен как зарезервированная переменная `object` (`object.status`). |
| условие | condition | `conditions[]` | Строка «поле — оператор — значение», которая должна быть истинной, чтобы процесс запустился. Все строки объединяются по «И». |
| оператор сравнения | operator (comparison) | `operator` | Способ сравнения в условии: `equals`, `not_equals`, `contains`, `not_contains`. |
| предзагрузка | preload | `preload` | Загрузка объекта из CRM в переменную — по `id` или по другому полю. |
| переменная | variable | `v1`, `task` | Именованный объект в памяти процесса. Создаётся предзагрузкой или действием `modify`, которое пишет в новое имя. |
| действие | action | `actions[]` | Шаг процесса: `preload`, `modify`, `save_object` или `start_process`. Действия выполняются последовательно. |
| изменение | modify (change) | `modify` | Действие, которое задаёт поле объекта или переменной. CRM не затрагивается, пока не запрошено сохранение. |
| тип изменения | change type | `change_type` | Как `modify` вычисляет новое значение: `set_value`, `set_from_variable`, `calculate`. |
| выражение | expression | `calculate` | Формула для типа изменения `calculate`, например `round(object.amount * 0.9, 2)`. |
| сохранение в CRM | save to CRM | `save_object`, `save_to_crm` | Отправка изменённых полей переменной в CRM (PUT, для нового объекта — POST). |
| запуск следующего процесса | start next process | `start_process` | Действие, которое асинхронно запускает один или несколько ведомых процессов и передаёт им событие и все переменные. |
| выполнение (запуск) | execution (run) | `executions` | Один прогон одного процесса по одному событию. Статусы: `running`, `retrying`, `completed`, `failed`. |
| шаг | step | `execution_actions` | Запись аудита об одном действии внутри выполнения: запрос, результат, попытки, длительность, статус. |
| источник запуска | trigger (source of a run) | `trigger`: `stream` / `manual` / `child` | Что запустило выполнение: событие CRM, ручной запуск из UI или родительский процесс. |
| ручной запуск | manual run | `POST /api/processes/{id}/run` | Запуск процесса из UI с введённым JSON-объектом, при желании без проверки условий (`force`). |
| однократный запуск для записи | run once per record | `run_once` | Флаг процесса: процесс выполняется для каждой записи CRM (`object_type` + `id`) не больше одного раза. |
| отметка однократного запуска | run-once mark | `process_object_runs` | Запись «процесс P уже запускался для записи X». Блокирует следующие запуски, пока её не сбросят. |
| повтор | retry | `retry_count` | Повторное выполнение упавшего шага после восстановимой ошибки, с экспоненциальной задержкой. |
| восстановимая / невосстановимая ошибка | recoverable / non-recoverable error | `RecoverableException` / `NonRecoverableException` | Временный сбой (таймаут, 5xx от CRM), который повторяется, / постоянный (4xx от CRM, ошибка настройки), который сразу завершает выполнение ошибкой. |
| очередь недоставленных сообщений (DLQ) | dead-letter queue | `crm_events:dlq` | Стрим, куда переносятся некорректные события и события, которые слишком много раз не удалось обработать. |
| приоритет | priority | `priority` | Порядок процессов одного типа объекта для одного события: меньшее значение выполняется раньше. |
| аудит | audit | | Сохранённая история выполнений и шагов. Её показывают журнал выполнения и страница выполнения. |
