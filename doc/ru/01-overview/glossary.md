# Глоссарий

Термины документации и интерфейса WPS: английские соответствия и имена, которые используются в коде.

<!-- lang-switch -->
[🇬🇧 English](../../en/01-overview/glossary.md) | 🇷🇺 Русский
<!-- /lang-switch -->

Документация на обоих языках использует эти термины единообразно. Технические имена в колонке «В коде» (поля, таблицы,
значения API) не переводятся.

## Процесс и событие

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| процесс | process | `processes` | Настроенное правило автоматизации: тип объекта, тип события, условия, предзагрузка, действия и константы. Хранится как JSON `definition`. |
| определение процесса | process definition | `definition` | JSON с ключами `conditions`, `preload`, `actions`, `constants`. Хранится в PostgreSQL как `jsonb`, поэтому порядок ключей объектов не сохраняется — упорядоченное задаётся списками. |
| версия процесса | process version | `version` | Счётчик сохранений процесса. Выполнение запоминает версию, с которой стартовало. |
| процесс верхнего уровня | top-level process | `is_child: false` | Процесс, который запускается напрямую событиями CRM своего типа объекта. |
| ведомый процесс | child process | `is_child: true` | Процесс, который запускается только действием `start_process` другого процесса. К событиям стрима напрямую не подбирается. |
| тип объекта (модуль CRM) | object type (CRM module) | `object_type` | Модуль CRM, на который реагирует процесс, например `Deals`, `Accounts`, `Leads`. Регистр важен. |
| приоритет | priority | `priority` | Порядок процессов одного типа объекта для одного события: меньшее значение выполняется раньше. |
| событие | event | сообщение стрима | Сообщение в Redis Stream `crm_events` о том, что запись CRM создана, изменена или удалена. Содержит поля записи и служебные поля контракта 2.0. |
| тип события | event type | `event_type`: `create` / `update` / `delete` | Что произошло с записью. Событие старого плагина без типа считается `create`, если `wps_is_update = "0"`, иначе `update`. |
| запускать при | run on | `trigger_on` | Список типов событий, на которые реагирует процесс. По умолчанию `["create", "update"]`; `[]` — только ручной запуск. Задаётся через API. |
| контракт 2.0 | contract 2.0 | `contract_version` | Формат обмена WPS ↔ плагин CRM: тип события, `before`, `changed_fields`, `wps_origin`, фильтры и связи в API `/api/v9`. |
| возможности CRM | CRM capabilities | `crm-capabilities` | Что умеет установленный плагин CRM (фильтр `nin`, связи, количество…). Действие, которому не хватает возможности, падает с `CRM_CAPABILITY_MISSING`. |
| объект события / исходный объект | event object / source object | `object` | Запись из события. В процессе доступна как зарезервированная переменная `object` (`object.status`). |
| значения до (старые значения) | values before (old values) | `object_before` | Старые значения **изменённых** полей из события контракта 2.0. Только для чтения; поле, которое не менялось, в ней отсутствует; `null` — старые значения неизвестны. |
| изменённые поля | changed fields | `changed_fields`, `sys.changed_fields` | Поля, изменённые сохранением, по данным плагина CRM. `null` — неизвестно, `[]` — сохранение ничего не изменило. |
| сведения о событии | event info | `event_info` | Тип события, изменённые поля, признак наличия `before`, происхождение (`wps_origin`) и признак старого формата. Хранятся в контексте выполнения, а не в `object`. |
| происхождение изменения | origin | `wps_origin`, заголовки `X-WPS-*` | Пометка события, если запись сохранил сам WPS: id выполнения, процесса и глубина. |

## Условия

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| условие | condition | `conditions[]` | Строка «поле — оператор — значение», которая должна быть истинной, чтобы процесс запустился. Строки в списке объединяются по «И». |
| группа условий | condition group | `{logical_operator, conditions, groups}` | Расширенная форма условий: «И» / «ИЛИ» и вложенные группы. Задаётся через API. |
| оператор сравнения | comparison operator | `operator` | Способ сравнения: `equals`, `greater_than`, `between`, `in`, `contains_any`, `is_empty`, `changed_to` и другие (всего 25). |
| зона сравнения (вид правой части) | compare with (value type) | `value_type`: `static` / `from_object_field` / `expression` | С чем сравнивается поле: со значением, с другим полем или с результатом выражения. |
| приведение типа | cast | `cast`, `cast_options` | Как понимать значения перед сравнением: `string`, `int`, `decimal`, `bool`, `date`, `datetime`, `list` и параметры (регистр, пробелы, формат). |
| строгий режим приведения | strict cast | `on_cast_error: "error"` | Значение, которое не приводится к типу, завершает проверку ошибкой, а не делает строку ложной. |
| относительная дата | relative date | `today+30d`, `now-24h`, `start_of_quarter` | Дата, которая считается от текущего момента в `WPS_TIMEZONE`. Рабочих дней нет. |
| ленивая предзагрузка | lazy preload | | Сначала проверяются условия по `object.*`; предзагрузка выполняется, только если они истинны и есть условия по переменным. |
| трасса условий | condition trace | `ConditionTrace`, `context.conditions` | Результат каждой строки: фактическое и ожидаемое значение, приведённые значения, `result`. |

## Действия и данные

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| действие (шаг) | action (step) | `actions[]`, `type` | Элемент программы процесса: `modify`, `save_object`, `send_email`, `foreach` … Выполняются по порядку. |
| блок | block | `condition`, `foreach`, `stop_process` | Действие со вложенными списками действий или управляющее ходом выполнения. |
| предзагрузка | preload | `preload` | Загрузка записи из CRM в переменную — по `id` или по другому полю. |
| переменная | variable | `v1`, `task`, `deals` | Именованное значение в памяти процесса. Создаётся предзагрузкой, `modify` в новое имя, `set_variable`, `find_records`, `http_request` или циклом. |
| переменная-список | list variable | `{items, count, has_more, ids}` | Результат `find_records`: найденные записи. Только для чтения. |
| изменение | modify (change) | `modify` | Действие, которое задаёт поле объекта или переменной. CRM не затрагивается, пока не запрошено сохранение. |
| тип изменения | change type | `change_type` | Как `modify` вычисляет новое значение: `set_value`, `set_from_variable`, `calculate`, `template`, `date_shift`, `increment`, `decrement`, `clear`, `append`, `prepend`, `remove`, `map`, `aggregate`. |
| выражение | expression | `calculate`, `value_type: expression`, `{{= … }}` | Формула языка выражений WPS, например `round(object.amount * 0.9, 2)`. |
| шаблон | template | `template`, `{{ … }}` | Текст с подстановками `{{ object.name }}`, фильтрами `{{ x \| default:'—' }}` и выражениями `{{= … }}`. Используется в письмах, уведомлениях, HTTP-запросах. |
| системные переменные | system variables | `sys.*` | Виртуальная переменная только для чтения: `sys.execution_id`, `sys.process_name`, `sys.trigger`, `sys.now`, `sys.changed_fields`, `sys.last_error` … |
| константы процесса | process constants | `definition.constants`, `config.*` | Значения, объявленные один раз в определении и читаемые как `config.<имя>`. Только для чтения. |
| сохранение в CRM | save to CRM | `save_object`, `save_to_crm` | Отправка изменённых полей переменной в CRM (PUT, для новой записи — POST). |
| запуск следующего процесса | start next process | `start_process` | Действие, которое асинхронно запускает ведомые процессы и передаёт им событие и все переменные. |
| секрет | secret | `secret://имя` | Учётные данные внешней системы (SMTP, токен, вебхук), зашифрованные в WPS. Процесс хранит только ссылку. |
| канал уведомления | notification channel | `crm_alert`, `telegram`, `slack`, `teams` | Куда `notify` доставляет сообщение. |
| стратегия назначения | assign strategy | `round_robin`, `least_busy`, `random`, `manager`, `user` | Как `assign` выбирает ответственного из пула пользователей. |

## Выполнение и аудит

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| выполнение (запуск) | execution (run) | `executions` | Один прогон одного процесса по одному событию. Статусы: `running`, `retrying`, `waiting`, `completed`, `failed`, `cancelled`. |
| ожидающее выполнение | waiting execution | `status: waiting`, `execution_waits` | Выполнение, приостановленное паузой `delay` или длинной задержкой повтора до срока `waiting_until`. Хранится в PostgreSQL, воркер свободен. |
| отменённое выполнение | cancelled execution | `status: cancelled` | Ожидающее выполнение, отменённое удалением процесса с `force=true`. |
| шаг аудита | step (audit record) | `execution_actions` | Запись об одном действии внутри выполнения: запрос, результат, попытки, длительность, статус. Статусы: `success`, `failed`, `skipped`, `waiting`. |
| программа процесса | process program | `pc`, `step_path` | Определение, скомпилированное в плоский список инструкций. `pc` — номер инструкции, `step_path` — место шага в определении (`actions[1].branches[0].actions[0]`). |
| итерация | iteration | `iteration` | Номер элемента цикла `foreach` с нуля; во вложенных циклах — `"2/0"`. |
| источник запуска | trigger (source of a run) | `trigger`: `stream` / `manual` / `child` | Что запустило выполнение: событие CRM, ручной запуск или родительский процесс. Не путать с `trigger_on`. |
| ручной запуск | manual run | `POST /api/processes/{id}/run` | Запуск процесса с введённым JSON-объектом, при желании без проверки условий (`force`). |
| однократный запуск для записи | run once per record | `run_once` | Флаг процесса: процесс выполняется для каждой записи CRM (`object_type` + `id`) не больше одного раза. |
| отметка однократного запуска | run-once mark | `process_object_runs` | Запись «процесс P уже запускался для записи X». Блокирует следующие запуски, пока её не сбросят. |
| повтор | retry | `retry`, `retry_count`, `attempts` | Повторное выполнение упавшего шага после восстановимой ошибки, с экспоненциальной задержкой. Профиль задаётся у шага (`max_attempts`, `base_delay`, `max_delay`, `retry_on`). |
| политика ошибки шага | error policy | `on_error`: `stop` / `continue` / `goto` | Что делать, если шаг упал: остановить выполнение, продолжить или перейти к шагу с `id`. Обработанные ошибки считаются в `handled_errors`. |
| восстановимая / невосстановимая ошибка | recoverable / non-recoverable error | `RecoverableException` / `NonRecoverableException` | Временный сбой (таймаут, 5xx, 429), который повторяется, / постоянный (4xx, ошибка настройки), который сразу завершает шаг ошибкой. |
| побочный эффект | side effect | `step_side_effects` | Внешний вызов шага: письмо, HTTP-запрос, уведомление. Записывается в журнал, чтобы повтор шага не отправил его дважды. |
| политика доставки | delivery policy | `delivery`: `at_most_once` / `at_least_once` | Что делать, если исход внешнего вызова неизвестен: не повторять (`UNKNOWN_OUTCOME`) или повторить. |
| ключ идемпотентности | idempotency key | `Idempotency-Key`, `idempotency_key` | Постоянный ключ `{execution_id}:{позиция шага}`, по которому внешняя система распознаёт повтор запроса. |
| очередь недоставленных сообщений (DLQ) | dead-letter queue | `crm_events:dlq` | Стрим, куда переносятся некорректные события и события, которые слишком много раз не удалось обработать. |
| аудит | audit | | Сохранённая история выполнений и шагов. Её показывают журнал выполнения и страница выполнения. |
| контекст выполнения | execution context | `context` | Снимок события, переменных, трассы условий и `sys.*` выполнения; пока выполнение идёт — живой контекст из Redis. |

## Интерфейс и доступ

| Термин (RU) | Термин (EN) | В коде | Определение |
|---|---|---|---|
| роль | role | `admin` / `editor` / `viewer` | Администратор, Редактор, Наблюдатель — набор разрешённых операций. |
| карточка процесса | process card | `/processes/{id}` | Страница процесса: свойства, условия, предзагрузка, действия, журнал выполнения, однократные запуски. |
| редактор процесса | process editor | `/processes/{id}/edit` | Форма с блоками «Конфигурация процесса», «Блок 1. Условия запуска», «Блок 2. Действия» и панелью «Переменные». |
| нередактируемая строка | read-only (passthrough) row | `passthrough` | Действие, которое редактор не умеет править (например, `send_email`): показывается серой строкой и сохраняется без изменений. |
